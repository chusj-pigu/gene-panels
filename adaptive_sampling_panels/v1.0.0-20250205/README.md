# v1.0.0-20250205

This folder contains the first versioned CHUSJ LP adaptive sampling panel release aligned with `gene_panel_lists/v1.0.0-20250205`.

## Files
- `2025-02-05-CHUSJ-Panel-20kb-LP.bed`
- `2025-02-05-CHUSJ-Panel-20kb-LP.xlsx`

## Difference from previous version
Compared with the legacy `v0.1.0-20251027` folder, this is the first release tied to a tracked gene panel list:
- base panel built from the `20250205_genes_list.txt` target list
- includes the manual loci from `20250205_loci.txt`
- standardized as a 20 kb padded CHUSJ LP panel export

## Notes
- The source target list contains 380 genes plus 3 manual loci.
